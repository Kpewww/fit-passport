# Sizing standards: the corrected list

Session 101g, 2026-10-22. This replaces every earlier list (chat, `size-calibration.md`
§4). Each row gives the edition, its status and the source for that status, and why we
want it.

**Status words:**
- **Current** or **withdrawn**: as the cited catalogue shows it.
- **Not verified**: no catalogue confirmed it.

**Correction from earlier lists.** DIN 61516 was recommended as "the source of the
European 44–56 numbers that most luxury houses use". That was unverified and has been
removed (see the end of this file).

## What no standard covers

The engine says "no basis" rather than guessing for these:
- **US letter sizes (S/M/L).** ASTM D6240 defines chest numbers only (read in its Table
  1).
- **Chinese letter sizes.** GB/T 1335 defines 号型 only.
- **Italian and French men's numbers (44–56).** No current standard found to define
  them. EN 13402-3 labels by body measurement instead.

For these, the evidence is each brand's own published chart (grade B).
